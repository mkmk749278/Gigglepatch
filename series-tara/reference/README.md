# Reference Images

Keeper reference images live here. Generate them with the prompts in
`../CHARACTER_REFERENCE_PROMPTS.md`, then save the chosen one for each with these
exact names:

```
tara_primary.png          ← generate and lock this one FIRST
tara_expressions.png
ravi_primary.png
chikoo_primary.png
kaaki_primary.png
kaaki_feathers_up.png
nandu_primary.png
ammamma_primary.png
lantern_unlit.png
lantern_three_lit.png
```

Upload these same files to the Flow **Characters** tab at the start of every
session, for every episode, forever.

**Do not regenerate them later.** New references mean the characters silently
change between episodes, and children spot that faster than adults do.
